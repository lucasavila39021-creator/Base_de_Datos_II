# FoodStore – Descripción del Producto
## Contexto
FoodStore es un proyecto integrador desarrollado para la materia **Base de Datos II** (UTN - FRM). El equipo está compuesto por Lucas Avila, Amanda Pagano y Mateo Lautaro Liendo.
## Qué es el sistema
Es un sistema de pedidos tipo delivery para un comercio gastronómico que permite registrar categorías, clientes, productos, pedidos y el detalle de cada venta con precios históricos congelados.
