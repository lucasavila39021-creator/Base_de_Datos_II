# Prácticas Base de Datos II

Repositorio central para los trabajos prácticos de la materia Base de Datos II.

## Estructura del Proyecto

* **`TP1_FoodStore/`**: Contiene el modelo de datos inicial del proyecto integrador (diagramas ER y script `schema.sql`).
* **`TP2_Concurrencia_IA/`**: Contiene la implementación de triggers para garantizar reglas de negocio, los informes de anomalías de concurrencia, ejercicios de lectura crítica y las Declaraciones de Uso de IA (DUIA).

---
*Protocolo de seguridad de datos aplicado estrictamente mediante transacciones locales y respaldos previos a DDL.*
